# Release Freeze — After RC1 Hardened

When decision is `RC_READY` or `RC_READY_WITH_EXTERNAL_STORE_STEPS`:

## Allowed

- P0 crash / save-loss / policy blockers
- P1 store-review blockers
- Metadata / screenshot export fixes
- Signing / TestFlight / Play Internal plumbing

## Forbidden

- New buildings / systems / regions
- Redesigns
- “Nice to have” gameplay
- Major dependency upgrades without security necessity

Everything else → `POST_LAUNCH_BACKLOG.md`
