# MetroBuilder — Roadmap 2.0

Quellenanalyse: v1.4.0-Archiv. Ziel: tieferer Mobile-City-Builder, nicht Feature-Spam.

## Leitprinzip

Jedes Feature muss eine **neue interessante Entscheidung** erzeugen — nicht nur mehr Inhalt.

Reihenfolge:

1. technische Basis stabilisieren  
2. Kernsimulation vertiefen  
3. Entscheidungen & Rückkopplungen  
4. Progression neu strukturieren  
5. Welt/Content ausbauen  
6. Retention & faire Monetarisierung  
7. erst dann Online/Social
